# Ejercicios de programación concurrente y sincronización

Conjunto de ejercicios de programación concurrente y sincronización,
tema que se imparte tanto en la asignatura Algoritmos y Estructuras de
Datos (ALED) del Grado en Ingeniería Biomédica como en Análisis y
Diseño de Software (ADSW) del Grado en Ingeniería de Tecnologías y
Servicios de Telecomunicación.

Este repositorio contiene las **soluciones** a los ejercicios, en
orden de dificultad creciente. Intenta resolver cada ejercicio por tu
cuenta antes de mirar el código en `src/`; consúltalo solo para
comprobar tu propia solución, no como punto de partida.

## Cómo importar el proyecto

Clona este repositorio e impórtalo en Eclipse como proyecto existente
(`.project` y `.classpath` ya están incluidos).

## Documentación

Los enunciados están en [`docs/Ejercicios-Concurrencia_Sincronizacion.pdf`](docs/Ejercicios-Concurrencia_Sincronizacion.pdf),
generado automáticamente a partir de su fuente LaTeX en Overleaf.
